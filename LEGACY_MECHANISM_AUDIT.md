## Extraction rule

The frozen legacy files are historical evidence, not executable authority. A mechanism is retained only after separating it from platform syntax, rhetorical framing, fixed thresholds, illustrative claims and contaminated generated text.

## Integrity findings

1. `legacy/GEOPOL_ALPHA v1.md` contains a trailing assistant-style response beginning “Sure, I can help you with that.” It remains preserved but is excluded from active modules.
2. The frozen source declares MIT in the README but contains no root `LICENSE` file. An actual licence file remains a release gate.
3. Several legacy files contain current-event examples and precise numerical claims without source ledgers. They are historical material, not trusted rules.
4. Platform names, tool counts and model comparisons are adapters or dated observations, never kernel invariants.
5. Git blob identity and SHA-256 preservation prove byte integrity, not factual correctness.
