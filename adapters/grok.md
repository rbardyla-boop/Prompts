# Grok Adapter

Adapter ID: `xai.grok`  
Status: specification; current tools must be discovered rather than inferred from legacy documents.

## Legacy compatibility

The frozen repository contains `/grok-*` commands and historical tool names. They are examples of earlier platform syntax, not kernel commands.

The adapter maps current Grok capabilities to PROMPTS v2 roles:

- public-source research;
- repository or file work when available;
- builder execution;
- fresh-context criticism;
- evidence packaging.

Unavailable legacy tools are recorded as unavailable. They are not simulated through invented results.

## Curiosity constraint

Curiosity, contrarian search and incentive analysis are heuristics. They may broaden hypotheses but cannot lower source standards, assume suppression, or authorize factual conclusions.

## Completion rule

The Grok worker submits evidence to the harness. A confident answer, rhetorical certainty or a platform status message is not a completion receipt.
